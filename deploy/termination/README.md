# Termination controller installation

Use [the production installation procedure](../../docs/termination-installation.md) with actual Terraform outputs, enabled normal enrollment receipts and fresh Kubernetes/Cilium node identity observations. `prepare.py` and `render.py` create separate reviewed identity/RBAC and workload JSON Lists; they never generate secrets or apply resources.

`check.sh` runs the bounded-input/authority/network negatives and pinned official schema checks. `tests/config_fixture.py` is public invented input solely for the real Rust CLI/credential constructor test. Its image, node identities, addresses and certification reference are not deployable or runtime certification evidence.
